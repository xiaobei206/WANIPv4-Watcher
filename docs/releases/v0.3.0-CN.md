# WANIPv4-Watcher v0.3.0 中文发布说明

## 本版重点

在保留原有 Go 监控核心的基础上，加入极简内置 Web 管理页面，并调整梅林安装方式：Go 二进制永久保存在 JFFS，普通路由器重启不再从 GitHub 下载。

## 内置 Web 管理

- 默认 TCP 10005，不设置网页登录密码；只绑定检测到的 LAN bridge 私有 IPv4，不监听 0.0.0.0、PPPoE/WAN。
- 管理 API 要求 Host 与 Origin 同源，不开放 CORS，并限制 JSON 请求体大小。
- 页面嵌入 Go 二进制，无前端框架、外部 CDN、数据库或独立 Web 服务。
- 支持配置保存、测试邮件、检测测试（不发送告警）、立即正式检测、最近日志和在线更新。
- SMTP 授权码不会通过配置读取 API 返回；编辑时密码框留空表示保持原授权码。

## 梅林 JFFS 永久安装

- ARM64 Go 二进制安装到 `/jffs/wanipv4-watcher/wanipv4-watcher`。
- 首次安装下载固定资产名并校验 SHA-256；升级既有 /tmp 版本时会先停止旧进程，再切换到 JFFS 永久程序。
- 普通重启直接运行 JFFS 程序，不依赖 GitHub；日志和 PID 仍在 /tmp。
- 手动更新先下载、校验、检查分区空间，再替换 JFFS 程序；更新失败时保持原程序运行。

## 定时与恢复

- IP 检查：路由器本地时间 07:00、19:00。
- watchdog：06:40、18:40 检查服务是否运行，必要时重新拉起。
- watchdog 不进行高频轮询，不需要额外常驻守护进程。

## 原有核心功能保持不变

四个国内来源、至少两个来源共识、完整 100.64.0.0/10 CGNAT、private_wan/mismatch/healthy/unknown、异常和恢复邮件通知及三次邮件重试全部保留。

## 梅林 SSH 管理菜单

管理器额外提供 `menu` 交互入口，可执行安装/修复、更新、状态、卸载和日志操作。重新运行安装器会识别并停止此前从 `/tmp` 运行的旧版进程，再切换到 JFFS 永久二进制。手动更新在下载或校验失败时不会先停止现有服务。

## 安全边界与验证

无登录密码意味着同一 LAN 内能访问页面的设备都拥有管理权限。仅在可信内网使用，禁止公网端口映射。若未检测到 br0/br-lan 等 LAN bridge，Web 管理会关闭，不会退回监听所有地址。

GitHub Actions 自动化构建成功不等于 ASUS RT-AC86U 386.9_0 已完成实机验收。

### 型号与 ABI 注意事项

- 表中型号用于快速定位芯片平台，**不表示该型号所有硬件版本、所有地区版或原厂固件都经过 WANIPv4-Watcher 实机验证**。同一商品名可能跨硬件版本更换 SoC，必须核对设备标签、硬件版本及系统信息。
- 特别注意：小米 AX3000T 的 RD03 / RD23 是 MediaTek MT7981B；新款 RD03v2 使用不同的 Qualcomm 硬件，不能直接套用 MT7981B 这一行。
- **MIPS 的大小端与浮点 ABI 是两个独立条件**：`mipsle` 与 `mips` 不能互换；`softfloat` 与 `hardfloat` 也不能互换。请以路由器当前 Linux 固件的实际 ELF / 软件包架构为准，不要只按品牌、商品名或 CPU 系列选择。
- 默认原厂固件若不是 Linux（例如专有 RouterOS），即使 CPU 芯片相同，也不能直接运行本项目的 Linux 二进制；需要设备运行兼容的 Linux 固件/环境。
- 早期 Release 的资产集和命名曾随项目演进而变化；本表统一说明当前稳定资产名。**新安装请从最新 Release 下载**，不要假设早期历史 Release 一定包含表内全部文件。
- 项目不编译 ARMv5、ARMv6 或 32 位 x86（386）。所有构建使用 `CGO_ENABLED=0`；CI 交叉编译通过不等于每个列举型号均已实机验证。
