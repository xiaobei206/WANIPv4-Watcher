# WANIPv4-Watcher v0.1.0 中文发布说明

## 版本定位

这是 WANIPv4-Watcher 的首个正式发布版本，目标是在 K2P / Padavan 路由器上观察 WAN 口 IPv4 与外部互联网实际看到的出口 IPv4 是否一致，并通过 QQ 邮件发送异常和恢复通知。

## 本版功能

### WAN 地址读取与外部交叉验证

- 根据 Linux IPv4 默认路由定位对应网卡，支持自动选择接口，也允许在配置中指定 wan_interface。
- 查询多个外部 IPv4 服务，并要求至少两个独立来源对有效 IPv4 给出一致结果；没有足够结果或来源之间无法形成明确共识时，不把结果当成已确认的公网地址。
- 初版默认检测来源为 ipify、icanhazip 和 AWS CheckIP。这些海外来源在部分国内网络中可能无法稳定访问，后续 v0.1.4 已改为固定使用四个国内来源。
- 提供 healthy、mismatch、private_wan 和 unknown 等状态，用于区分 WAN/出口一致、地址不一致、WAN 地址非公网以及本轮无法判定。

### 地址分类与邮件告警

- 初步识别 RFC1918 私有 IPv4、运营商共享地址段 100.64.0.0/10，以及常见不可全球路由的特殊用途地址。
- 使用 QQ 邮箱 SMTP SSL 465 端口发送中文告警邮件，并支持异常后的恢复通知；是否发送启动通知和恢复通知可通过配置控制。
- 邮件配置由 JSON 提供，密码字段应填写 QQ 邮箱 SMTP 授权码，不是 QQ 登录密码。
- 日志采用有限大小文件并保留一个轮转备份，降低持续运行时的日志膨胀风险。

### 命令行与 Padavan 部署基础

- 提供一次检测、测试邮件、配置检查、显示版本等命令行模式，便于安装后先验证配置和 SMTP。
- 提供不含真实凭证的配置模板、Padavan 安装/启动/停止/状态与卸载脚本，以及中文安装和排错文档。
- Go 程序只使用标准库，支持为 Padavan 常见的 Linux MIPS little-endian soft-float 环境交叉编译，不依赖路由器上的 libc/OpenSSL 动态库。

## 初版默认行为

- 默认检测周期为每 30 秒一次，间隔可由配置调整；后续 v0.1.3 改为每天 07:00 和 19:00 两次。
- 旧式 SSH 安装配置存放于 /etc/storage/wanipv4-watcher.json；运行程序、日志和部分启动文件使用 /tmp。
- 初版默认使用海外检测源，不能假设这些站点在每个国内宽带网络中都可稳定访问。

## 测试与交付

本版通过仓库的 Go 测试、静态检查和交叉编译发布流程，提供路由器目标的 MIPSLE soft-float 二进制、Linux AMD64 诊断二进制、源码归档与 SHA-256 校验清单。自动构建成功不等于已在真实 K2P 设备上完成全部网络与邮件验收。

## 后续版本已修正的已知问题

- v0.1.1 修复了 QQ SMTP 465 隐式 TLS 认证兼容问题、PLAIN 认证分隔符编码问题，以及外部检测结果票数打平时仍可能选出一个地址的问题。
- v0.1.2 修复 Padavan 的 /etc/storage 写入后未主动保存到闪存的问题。
- v0.1.3 改为固定时段检测，减少不必要的持续轮询。
- v0.1.4 将外部检测源切换为四个指定的国内服务。

因此，此说明用于记录 v0.1.0 当时的功能与限制；新部署应使用仓库当前最新 Release，而不是重新安装本初版。
