# WANIPv4-Watcher v0.1.4 中文发布说明

## 版本重点

本版根据国内家庭宽带环境，将公网出口 IPv4 检测固定到四个指定的国内服务，并兼容不同服务返回纯文本、说明文本或 JSON 的格式。旧配置即使保留海外 URL，程序加载后也会覆盖为这四个固定来源。

## 具体变化

### 固定四个国内检测源

- IPIP： https://myip.ipip.net
- 3322： http://ip.3322.net
- CIP.cc： https://cip.cc
- IP9： https://ip9.com.cn/get

程序不再调用 ipify、icanhazip、AWS CheckIP 等海外检测站。该行为也不依赖用户是否手动编辑过旧 JSON：载入配置时会强制替换 external_ip_urls，避免升级后仍访问以前的海外接口。

### 兼容响应格式并坚持多源共识

- 支持解析 IPIP 和 CIP.cc 的说明文本、3322 返回的纯文本 IPv4、IP9 JSON 中的 data.ip 字段。
- 单个服务无响应、返回无效 IPv4、返回私网地址或其他非公网地址时，不把该值作为已确认的外部公网地址。
- 至少两个独立来源对同一个有效公网 IPv4 达成一致才形成结果；来源数量不足或结果冲突时保持 unknown，不猜测。
- 增加来源列表固定、各类响应格式以及旧配置中海外 URL 被替换的回归测试。

### 兼顾中国网络可达性与传输差异

- 采用面向国内网络的来源，减少海外服务连接失败造成的 unknown 情况。
- 3322 的公开接口为 HTTP，而不是 HTTPS；它的响应不会单独决定最终结果，必须与其他来源交叉验证。

## 升级与兼容

- v0.1.3 起的 check_times 定时配置保持不变：默认每天 07:00、19:00 检查一次。
- 旧配置字段不要求用户手动迁移；升级后程序会在内存中重设检测源列表。
- 当前版本建议通过对应 Release 下载二进制并核验 SHA-256；新式 Padavan 启动器会自动下载并验证。

## 测试与交付

本版新增外部响应解析、四个固定来源和旧配置迁移测试。GitHub Actions 的 Go 测试、go vet、Shell 语法检查、Linux MIPSLE soft-float 与 AMD64 构建，以及 Release 资产发布流程均通过。

## 已知限制

- 3322 接口使用 HTTP；结果依靠多个来源交叉验证，不能视为每个来源都具备同等的传输保护。
- 家庭路由器仍需能访问这些站点。个别站点临时故障可能导致本轮无法形成共识，但程序会选择 unknown 而不是擅自判断地址发生变化。
- 自动交叉验证不能取代真实 K2P 上的 WAN 接口与 QQ SMTP 实机验收。
