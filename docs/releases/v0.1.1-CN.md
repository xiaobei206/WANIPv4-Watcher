# WANIPv4-Watcher v0.1.1 中文发布说明

## 版本重点

本版主要修复首发后发现的 QQ 邮箱 SMTP 认证兼容问题，并收紧多来源检测结果的冲突处理。配置文件字段和 Padavan 的基础部署方式保持兼容。

## 具体修复

### 修复 QQ SMTP SSL 465 认证

- 明确处理 smtp.qq.com:465 的隐式 TLS 连接与 Go net/smtp 认证能力之间的兼容性。
- 只有在 TLS 连接已经建立、满足认证条件后才进行 PLAIN 认证，避免认证阶段因为连接安全状态判断不一致而失败。
- 修正 SMTP PLAIN 认证数据中的字段分隔符，写入真实的 NUL 字节，而不是字面量反斜线字符序列。
- 邮件发送测试模式继续可用，安装后可先用测试邮件确认邮箱、授权码和收件地址正确。

### 处理外部 IP 多数票打平

- 当来源返回多个不同 IPv4，且最高票数相同，程序不再依赖遍历顺序或任意选择其中一个结果。
- 打平、来源不足或无法获得可信共识时保持 unknown，让程序明确表示本轮无法判断，避免由错误地址触发误告警或错误恢复通知。
- 新增对应的回归单元测试，固定这一行为。

## 配置与升级

- 继续使用 v0.1.0 的 JSON 配置结构；一般不需要重新生成配置。
- SMTP 用户名、发件地址、收件地址应填写真实邮箱；密码使用 QQ 邮箱 SMTP 授权码。
- 如果升级后仍无法发信，请先运行测试邮件模式并检查日志；不要把真实授权码提交到公开仓库或发到截图中。

## 测试与构建

本版通过 Go 单元测试、go vet 静态分析以及 Linux MIPSLE soft-float 交叉编译。Release 持续提供路由器二进制、AMD64 诊断二进制、源码归档和 SHA-256 校验清单。

## 本版仍保留的限制

- 默认检测源仍是 ipify、icanhazip 和 AWS CheckIP；国内网络可达性问题在 v0.1.4 才通过更换检测源处理。
- 检测行为仍按配置间隔轮询；v0.1.3 才改为每天 07:00、19:00。
- Padavan /etc/storage 的显式闪存保存问题在 v0.1.2 处理。
