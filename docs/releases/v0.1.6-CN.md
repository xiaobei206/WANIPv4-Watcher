# WANIPv4-Watcher v0.1.6 中文发布说明

## 版本概述

本版重点完善 WAN IPv4 的特殊地址分类与告警解释，避免用户看到运营商共享地址时还需要自行判断它属于哪一类。程序仍只使用 IPIP、3322、CIP.cc、IP9 四个国内检测源，默认每天 07:00 和 19:00 检测。

## 本版更新

### 1. 明确覆盖完整 CGNAT 地址范围

- 按 CIDR 网段匹配 `100.64.0.0/10`，覆盖 `100.64.0.0–100.127.255.255`，并非只判断 `100.64.x.x`。
- 你反馈的 `100.71.x.x` 明确属于该范围，会被判断为运营商共享地址（CGNAT）和非公网 WAN 地址。
- 不把整个 `100.0.0.0/8` 粗暴封锁；`100.128.0.1` 等位于该 /10 之外的地址不会仅因首段为 100 就被归为 CGNAT。

### 2. 扩充特殊地址分类与中文诊断

程序对下列类别给出明确的中文原因，而不是统一返回“不是公网地址”：

- RFC1918 私有地址。
- 运营商共享地址（CGNAT）。
- 回环地址、链路本地地址、组播地址和未指定地址。
- IETF 协议专用、保留地址、网络基准测试地址及文档示例地址段。
- 按 IANA 特殊用途地址登记表保留 `192.0.0.9` 和 `192.0.0.10` 的全球可达例外。

收到 `private_wan` 告警时，日志和邮件说明会展示具体类别；CGNAT 说明包含完整网段范围。

### 3. 新增回归测试

- 覆盖 `100.71.0.1`、`100.71.33.44`、`100.127.255.255` 等网段内部地址。
- 覆盖 `100.63.255.255` 和 `100.128.0.1` 等相邻范围，防止边界判断过度扩大。
- 检查诊断文本明确包含 CGNAT 和完整范围。

### 4. 构建与交付验证

本版 GitHub Actions 已通过以下检查：

- Go 单元测试（`go test ./...`）。
- 静态分析（`go vet ./...`）。
- Shell 启动/安装/卸载脚本语法检查。
- Padavan 目标：`linux/mipsle`、`GOMIPS=softfloat`、`CGO_ENABLED=0`。
- Linux AMD64 诊断程序编译。
- SHA-256 校验清单、构建报告及 GitHub Release 发布。

## 安装与升级

新部署请打开仓库首页 README，找到“快速部署到 Padavan”并将短启动区块追加到“参数设置 → 脚本 → 在路由器启动后执行”。启动器会自动下载并校验 Release 中的 MIPSLE Go 程序，赋予执行权限并启动。无需手动下载二进制。

如果已经部署 v0.1.5，启动脚本使用 `releases/latest/download` 获取最新版；v0.1.6 发布后，下次路由器重新执行启动器时会取得新版本。程序仍默认每天上午 07:00 和晚上 19:00 检测。

## 已知限制

- GitHub Actions 构建通过不代表已在真实 K2P Padavan 路由器上完成实机验收。
- 仍需在用户设备上确认 WAN 接口自动识别、四个国内检测源的实际可达性及 QQ SMTP 投递。
- `http://ip.3322.net` 使用 HTTP，其返回值须与其他检测源交叉验证。
- `private_wan` 说明 WAN 口拿到的地址不是全球可路由公网 IPv4，但不能仅凭该地址确定是运营商主动变更，光猫路由模式、上游 NAT 或 VPN 也可能造成这种现象。
