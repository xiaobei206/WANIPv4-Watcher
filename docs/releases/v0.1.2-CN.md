# WANIPv4-Watcher v0.1.2 中文发布说明

## 版本重点

本版修复 Padavan 安装器写入配置和启动脚本后，没有明确把 /etc/storage 内容保存到闪存的问题。它同时让安装器更适合重复运行，以便修复已经装好的旧版，而不是只能重新安装。

## 具体变化

### 安装后主动保存到 Padavan 闪存

- 安装/更新脚本在写入启动钩子与初始配置后，查找 /sbin/mtd_storage.sh 或 /usr/sbin/mtd_storage.sh 并执行 save。
- 如果找不到保存程序或保存操作失败，安装器会输出明确错误，并提示使用 Padavan Web 管理页面里的“保存 /etc/storage/ 内容到闪存”操作；不再把“写入文件”误当成“已经持久化”。
- 手工修改 /etc/storage/wanipv4-watcher.json 后，仍需再次执行保存到闪存操作，否则路由器重启时可能恢复成旧配置。

### 安装与开机脚本更安全

- 重跑安装器会刷新本工具自己的标记区块，而不是重复附加多份启动内容。
- 保留 started_script.sh 中与本工具无关的用户命令，不覆盖原有启动设置。
- 增加配置模板检查：如果 QQ 邮箱和授权码仍是示例占位符，就记录原因并停止无意义启动。
- 启动过程中下载失败时增加重试处理，以适应路由器网络和 DNS 尚未完全就绪的情况。
- 卸载脚本在移除本工具启动钩子后同样尝试保存 /etc/storage，避免删除动作在重启后反弹。

## 安装和升级建议

如果设备已经安装早期版本，可以重新运行本版安装器，让它刷新自己的启动区块并尝试保存闪存；运行前请保留备份，并确认自己已有的 started_script.sh 其他内容未被误删。旧式 SSH 安装继续使用 /etc/storage/wanipv4-watcher.json，运行程序和日志使用 /tmp。

## 测试与交付

本版经过 Go 测试、静态检查、MIPSLE soft-float 路由器目标和 Linux AMD64 诊断目标的构建流程，并通过 Release 发布。自动化检查不能取代真实 K2P/Padavan 上的断电重启验证；建议实际检查重启后启动项仍存在、程序能下载并且 QQ 测试邮件可送达。

## 本版仍保留的限制

- 默认检测间隔仍为配置中的轮询间隔；v0.1.3 改为每天两次。
- 默认外部 IPv4 来源仍是海外服务；v0.1.4 才切换到四个指定的国内来源。
- 真实路由器的 WAN 接口名称、上游 NAT 和 SMTP 投递情况仍需设备侧确认。
