# WANIPv4-Watcher v0.2.2 中文发布说明

## 本版修正：二进制资产只保留固定名称

从本版开始，每种架构只发布一份二进制，文件名不包含版本号。版本信息由 GitHub Release 标题、标签和本页说明体现，不再通过重复的文件名表达。

- 安装器和手动下载统一使用固定资产名，例如 `wanipv4-watcher-linux-arm64`。
- 自动更新统一通过 `https://github.com/xiaobei206/WANIPv4-Watcher/releases/latest/download/资产名` 获取最新正式版。
- 每个 Release 只附带一份 `checksums.txt`，其条目使用固定二进制资产名。
- 源码归档和中文构建报告仍按版本命名，便于保存和追溯；它们不是路由器安装器使用的二进制包。
- v0.2.0 和 v0.2.1 的 Release 标题与文字说明保留；本版发布成功后清除这两版的手动上传附件。

## 固定资产名与架构对照

| Release 二进制文件名 | 常见路由器 / 用途（示例，不代表全部硬件修订版均实测） |
|---|---|
| `wanipv4-watcher-linux-arm64` | ASUS RT-AC86U（ASUSWRT-Merlin）；Xiaomi Router AX3000T、Redmi AX6000、Xiaomi AX3600（相应 ARM64/OpenWrt 固件） |
| `wanipv4-watcher-linux-armv7` | ASUS RT-AC68U；Netgear R7800；Linksys WRT1900ACS（须确认所用固件为 32 位 ARMv7） |
| `wanipv4-watcher-linux-amd64` | OpenWrt / iStoreOS x86-64 软路由；Intel N100、N5105、J4125 等 x86-64 迷你主机 |
| `wanipv4-watcher-linux-mipsle-softfloat` | TP-Link K2P（Padavan）；Xiaomi Router 3G、Newifi D2 等常见 MT7621 小端设备（仍须核对固件 ABI） |
| `wanipv4-watcher-linux-mipsle-hardfloat` | 少数明确采用小端 MIPS hard-float ABI 的固件/设备；必须确认 ABI |
| `wanipv4-watcher-linux-mips-softfloat` | TP-Link Archer C7 v2/v3、TL-WR1043ND v2/v3、Netgear WNDR4300 等部分大端 MIPS 设备（须核对硬件版本与固件目标） |
| `wanipv4-watcher-linux-mips-hardfloat` | 明确采用大端 MIPS hard-float ABI 的固件；需按固件构建目标判断 |
| `wanipv4-watcher-linux-riscv64` | StarFive VisionFive 2、Milk-V Mars 等运行 Linux 的 RISC-V 64 位开发板 |

本版不构建 ARMv6、ARMv5 或 32 位 x86（386）。MIPS 用户必须同时确认大小端与浮点 ABI，不能只根据 CPU 品牌或路由器商品名选择文件。

## 自动化验证与实机边界

GitHub Actions 运行 Go 单元测试、`go vet`、Shell 语法检查、所有目标交叉编译及二进制格式检查，并生成单份 SHA-256 清单。CI 通过表示自动化检查及构建通过，不表示所有路由器型号均已完成实机验证。

- ASUSWRT-Merlin：继续使用 [梅林中文安装指南](https://github.com/xiaobei206/WANIPv4-Watcher/blob/main/docs/MERLIN-INSTALL-CN.md)。
- Padavan：继续使用 [Padavan 安装指南](https://github.com/xiaobei206/WANIPv4-Watcher/blob/main/docs/PADAVAN-INSTALL-CN.md)。
- 其他 Linux 设备：依据 Release 固定资产名选择与 CPU 架构、大小端及 ABI 匹配的文件。
