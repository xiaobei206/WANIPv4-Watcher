# WANIPv4-Watcher v0.2.1 中文发布说明

## 本版修正

本版修正 Release 资产命名与型号说明的呈现方式：

- 恢复版本化二进制文件名，统一采用 `WANIPv4-Watcher-v0.2.1-linux-架构` 形式，方便人工下载、归档和确认版本。
- 同时保留无版本号稳定下载名（`wanipv4-watcher-linux-架构`），供梅林/Padavan 等启动器按固定 URL 下载。两个名称指向相同架构、相同版本的二进制。
- 常见路由器型号和用途集中放在本说明最底部的对照表里；不通过修改包名或资产标签来表达兼容信息。

## 编译目标

本版继续发布以下 Linux 目标，全部通过 `CGO_ENABLED=0` 交叉编译：

- ARM64 / AArch64
- 32 位 ARMv7
- x86-64（AMD64）
- MIPS 小端 soft-float / hard-float
- MIPS 大端 soft-float / hard-float
- RISC-V 64-bit

不构建 ARMv6、ARMv5 或 32 位 x86（386）。MIPS 用户必须确认大小端和浮点 ABI；不能只根据 CPU 厂商或路由器商品名选择文件。

## 安装方式

- ASUSWRT-Merlin：使用 [梅林中文安装指南](https://github.com/xiaobei206/WANIPv4-Watcher/blob/main/docs/MERLIN-INSTALL-CN.md)。安装器会检查 ARM64 架构和 JFFS 自定义脚本设置，保留已有启动脚本内容。
- Padavan：保持原有 K2P 安装方式与 `linux-mipsle-softfloat` 稳定文件名不变。
- 其他 Linux 路由器/软路由：可以使用 Release 对应架构的二进制，手动校验 SHA-256；专用安装器在实际需要时再逐个增加。

## 验证范围

GitHub Actions 会运行 Go 单元测试、`go vet`、Shell 语法检查、所有目标的交叉编译、二进制格式检查，并生成 SHA-256 清单和中文构建报告。CI 通过表示自动化检查及构建通过，不表示每种路由器都已完成实机验证。

### 型号与 ABI 注意事项

- 表中型号用于快速定位芯片平台，**不表示该型号所有硬件版本、所有地区版或原厂固件都经过 WANIPv4-Watcher 实机验证**。同一商品名可能跨硬件版本更换 SoC，必须核对设备标签、硬件版本及系统信息。
- 特别注意：小米 AX3000T 的 RD03 / RD23 是 MediaTek MT7981B；新款 RD03v2 使用不同的 Qualcomm 硬件，不能直接套用 MT7981B 这一行。
- **MIPS 的大小端与浮点 ABI 是两个独立条件**：`mipsle` 与 `mips` 不能互换；`softfloat` 与 `hardfloat` 也不能互换。请以路由器当前 Linux 固件的实际 ELF / 软件包架构为准，不要只按品牌、商品名或 CPU 系列选择。
- 默认原厂固件若不是 Linux（例如专有 RouterOS），即使 CPU 芯片相同，也不能直接运行本项目的 Linux 二进制；需要设备运行兼容的 Linux 固件/环境。
- 早期 Release 的资产集和命名曾随项目演进而变化；本表统一说明当前稳定资产名。**新安装请从最新 Release 下载**，不要假设早期历史 Release 一定包含表内全部文件。
- 项目不编译 ARMv5、ARMv6 或 32 位 x86（386）。所有构建使用 `CGO_ENABLED=0`；CI 交叉编译通过不等于每个列举型号均已实机验证。
