# WANIPv4-Watcher v0.3.1 中文发布说明

## 本版修正：所有首次配置统一在 WebUI 完成

- 梅林 Shell 安装器不再询问 WAN 接口、邮箱、QQ SMTP 授权码或检测时间。
- 安装器只负责部署 Go 程序、创建默认空凭证配置、管理脚本和开机启动项。
- SMTP 尚未配置时 Go 服务仍启动 WebUI；定时检测暂停等待完成 SMTP 设置。
- Web 配置读取接口不回传已保存的 WAN/邮件字段或授权码。
- 保存成功后立即清空输入框、折叠配置区域，只显示“已保存”。
- 再次打开配置时字段保持空白；空白字段表示保持已有值，填写后才更新相应配置。
- 旧版本已保存的 JFFS 配置和授权码不覆盖、不回显。

## 使用步骤

1. SSH 执行安装命令。
2. 安装器只安装并启动服务，不要求 Shell 输入业务配置。
3. 浏览器打开 `http://路由器LAN地址:10005`。
4. 展开配置，填写 WAN、检测时间、QQ SMTP 和收件地址。
5. 保存后输入框清空并自动折叠，显示“已保存”。
6. 点击测试邮件验证 SMTP 配置。

四源共识、完整 CGNAT /10、异常与恢复通知、TCP 10005、无密码 LAN-only Web、JFFS 永久安装及 06:40/18:40 watchdog 保持不变。

CI 成功不代表已完成 RT-AC86U 386.9_0 实机验收。

### 型号与 ABI 注意事项

- 表中型号用于快速定位芯片平台，**不表示该型号所有硬件版本、所有地区版或原厂固件都经过 WANIPv4-Watcher 实机验证**。同一商品名可能跨硬件版本更换 SoC，必须核对设备标签、硬件版本及系统信息。
- 特别注意：小米 AX3000T 的 RD03 / RD23 是 MediaTek MT7981B；新款 RD03v2 使用不同的 Qualcomm 硬件，不能直接套用 MT7981B 这一行。
- **MIPS 的大小端与浮点 ABI 是两个独立条件**：`mipsle` 与 `mips` 不能互换；`softfloat` 与 `hardfloat` 也不能互换。请以路由器当前 Linux 固件的实际 ELF / 软件包架构为准，不要只按品牌、商品名或 CPU 系列选择。
- 默认原厂固件若不是 Linux（例如专有 RouterOS），即使 CPU 芯片相同，也不能直接运行本项目的 Linux 二进制；需要设备运行兼容的 Linux 固件/环境。
- 早期 Release 的资产集和命名曾随项目演进而变化；本表统一说明当前稳定资产名。**新安装请从最新 Release 下载**，不要假设早期历史 Release 一定包含表内全部文件。
- 项目不编译 ARMv5、ARMv6 或 32 位 x86（386）。所有构建使用 `CGO_ENABLED=0`；CI 交叉编译通过不等于每个列举型号均已实机验证。
