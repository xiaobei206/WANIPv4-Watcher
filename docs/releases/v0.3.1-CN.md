# WANIPv4-Watcher v0.3.1 中文发布说明

## 本版修正：所有首次配置统一在 WebUI 完成

- 梅林 Shell 安装器不再询问 WAN 接口、邮箱、QQ SMTP 授权码或检测时间。
- 安装器只负责部署 Go 程序、创建默认空凭证配置、管理脚本和开机启动项。
- SMTP 尚未配置时 Go 服务仍启动 WebUI；定时检测暂停等待完成 SMTP 设置。
- Web 配置读取接口不回传已保存的 WAN/邮件字段或授权码。
- 保存成功后立即清空输入框、折叠配置区域，只显示“已保存”。
- 再次打开配置时字段保持空白；空白字段表示保持已有值，填写后才更新相应配置。
- 旧版本已保存的 JFFS 配置和授权码不覆盖、不回显。

## 使用步骤

1. SSH 执行安装命令。
2. 安装器只安装并启动服务，不要求 Shell 输入业务配置。
3. 浏览器打开 `http://路由器LAN地址:10005`。
4. 展开配置，填写 WAN、检测时间、QQ SMTP 和收件地址。
5. 保存后输入框清空并自动折叠，显示“已保存”。
6. 点击测试邮件验证 SMTP 配置。

四源共识、完整 CGNAT /10、异常与恢复通知、TCP 10005、无密码 LAN-only Web、JFFS 永久安装及 06:40/18:40 watchdog 保持不变。
